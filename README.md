# 학생, 안경 좀 벗어볼까요?

2027학년도 수능을 앞두고 불거진 AI 스마트안경·초소형 카메라 부정행위 논란을 풍자하는 브라우저 게임입니다.

플레이어는 장비를 하나도 받지 못한 제3시험실 감독관입니다. 수험생 20명 가운데 AI 안경이나 카메라 단추를 달고 들어온 학생을 눈과 OMR 카드만 보고 가려내야 합니다. 교시가 지날 때마다 기기는 더 작고 조용해지고, 대책은 계속 "검토 중"입니다.

## 플레이

처음 접속하면 인트로 다음에 3쪽짜리 하는 법이 나오고, 그 뒤에 일반 모드(무작위 시험실에서 혼자 감독)와 도전 모드 중 하나를 고릅니다. 하는 법은 모드 선택 화면에서 다시 볼 수 있습니다.


- 학생을 누르면 전신·얼굴·단추 확대 화면과 관찰 기록이 나옵니다.
- 의심 표시를 해 두면 교시가 끝난 뒤 한꺼번에 확인합니다.
- 급할 때는 교시당 2회까지 현장에서 안경 또는 복장을 확인할 수 있습니다. 엉뚱한 곳을 보거나 정직한 학생을 붙잡으면 민원이 쌓이고, 6건이면 감독관이 교체됩니다.
- 수상한 행동이 이어진 바로 뒤에 OMR 마킹이 갑자기 늘어나는지가 핵심 단서입니다.

## 도전 모드

- 오늘의 시험실: 날짜마다 정해진 코드로, 같은 날 플레이하는 사람은 모두 같은 시험실을 감독합니다.
- 도전 코드: 결과 화면의 5자리 코드를 친구에게 보내면 학생 배치와 부정행위자가 똑같은 시험실에서 겨룰 수 있습니다.
- 옆 시험실 라이벌: 신입 이 감독관, 20년차 박 부장, 전설의 최 교감 가운데 한 명과 실시간으로 점수를 겨룹니다.
- 친구와 번갈아 대결: 휴대폰 하나로 두 명이 같은 시험실을 차례로 감독하고 결과를 비교합니다.
- 연속 적발 콤보(최대 2배)와 현장 적발 시간 보너스가 있습니다.

## 공유 카드와 소리

- 결과 화면의 "공유 카드 보기"를 누르면 등급, 점수, 20석 결과, 라이벌 승패, 도전 코드를 담은 이미지 카드가 나옵니다. 끝까지 감독했든 중간에 교체됐든 똑같이 만들 수 있고, 친구 대결 결과에도 따로 카드가 있습니다.
- 음악과 효과음은 외부 파일 없이 브라우저에서 직접 합성합니다. 화면 위 🔊 버튼이나 모드 선택 화면의 "소리 설정"에서 음악과 효과음 크기를 따로 조절하거나 모두 끌 수 있습니다.

## 실행

`index.html` 파일 하나로 동작합니다. 서버나 외부 라이브러리가 필요 없고, 기록은 브라우저(localStorage)에만 저장됩니다.

## 알림

풍자 게임입니다. 게임에 나오는 업체(글래스노바), 공문, 뉴스 속보, 인물은 모두 지어낸 것입니다. 마지막 화면의 수능 유의사항(스마트기기 착용만으로 당해 시험 무효, 다음 해 응시 자격 제한)은 교육부의 2027학년도 수능 안내를 따른 것입니다.
